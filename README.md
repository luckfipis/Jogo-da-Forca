# 🎮 Jogo da Forca

Jogo da forca completo desenvolvido com **React** e **Vite**, com efeitos sonoros e interface interativa.

---

## 🚀 Funcionalidades

- ✅ Sorteio aleatório de palavras a cada partida
- ✅ Teclado virtual para adivinhar as letras
- ✅ Contador de tentativas restantes
- ✅ Efeitos sonoros para acertos e erros
- ✅ Tela de vitória e derrota com opção de reiniciar

## 📦 Como rodar o projeto

1. Clone o repositório:
```bash
git clone https://github.com/luckfipis/Jogo-da-Forca.git
```

2. Acesse a pasta do projeto:
```bash
cd Jogo-da-Forca
```

3. Instale as dependências:
```bash
npm install
```

4. Rode o servidor de desenvolvimento:
```bash
npm run dev
```

5. Acesse no navegador: `http://localhost:5173`
